Reliability

Messages That Tell the Truth

For a week we drove the whole interface against simulators and a real PHD2, looking for one thing: places where the application said something that was not so. A mount that vanished mid-session while the screen still read “Disconnect”. A guide error in the wrong unit. Five tracking charts that could never draw. A machine-learning screen that said “Active” because tracking was running.
By Bogdan • October 3, 2026 • DEV LOG • v1.4.6 PRO

The most dangerous sentence in an observatory program is a reassuring one that happens to be false. Connected. Active. Guiding. A user who has been told so does not go and check.

We spent a week hunting for exactly that — moments where the application said something that was not so — by driving the whole interface against simulators and a real PHD2. The hunt turned up fewer crashes than falsehoods.

A Mount That Disappears

If the mount vanished during a session — unplugged, rebooted, Wi-Fi lost — the application used to keep showing Disconnect, with frozen coordinates and no message at all. It now says Lost contact with the mount, with the real reason, within about fifteen seconds. The coordinates are shown as unavailable, and the application tells you when the link is back, and when the driver has restarted and must be reconnected.

Related fixes followed. Refresh no longer reports Connected for a mount that cannot be reached. A failed connection explains itself — refused, no answer, unknown host — instead of offering a generic checklist. And the log file no longer receives an error a second: in one test a disconnected mount had produced 430 log lines, and it now produces 13.

Ten Seconds, Every Time

Connecting to PHD2 froze the application for ten seconds, every time. An invisible byte-order mark at the start of the first request made PHD2 reject it, and the application then simply waited for its own timeout. Without the mark, the connection takes about a tenth of a second.

A test server built on a standard stream reader could never have shown this, because the reader quietly strips the mark. Only the real PHD2 reproduced it.

Pixels Are Not Arcseconds

The guide RMS never moved. The application asked PHD2 for a statistics method that PHD2 does not have; it is now computed from the guide steps themselves.

Worse, guide errors were displayed in arcseconds although PHD2 reports them in pixels, so every figure was understated by the pixel scale — by a factor of 4.3 on a 176 mm refractor setup. They are now converted with PHD2’s own pixel scale, and the unit is shown. The PHD2 panel also gains a guide-error graph, and the guide star PHD2 is tracking appears live in the guide-camera feed, with a clear star lost state.

A number without its unit is a rumour. On guide errors that were 4.3 times too small

Charts That Could Never Draw

Five of the six tracking charts in the Advanced Features window could never draw anything. The plot kept an old, empty model; the time window was 0.12 seconds wide; and the vertical axes were fixed at plus or minus one arcsecond.

They draw now. The window also reconnects to the tracking controller when it is recreated, catches up on what happened before it was opened, and shows real applied corrections and real altitude-azimuth errors. The session statistics and the Plate Solve tab, which nothing had ever fed, are fed by the tracking loop.

“Active” Is Not a Status

The machine-learning screens said Active whenever tracking was running. They now report whether a model exists, how good it is, and why it is or is not being applied. Reset really deletes the model.

The training itself was repaired in four ways. It no longer retrains on every cycle once its buffer is full. It no longer freezes the tracking thread. It learns the next step rather than a value it was given as an input — in other words, the answer no longer leaks into the question. And it is judged on a chronological hold-out instead of a shuffled split of a series whose neighbours resemble each other.

Mosaics, Placed by the Stars

Mosaic panels are now placed from the stars they share. A flipped or rotated camera, and the field rotation of an alt-az mount, are therefore measured rather than assumed. That repairs the automatic stitch after a mosaic sequence, which now averages several frames per panel and uses your overlap, and the mosaic mode of the Stacking window, where panels used to land on top of each other. A panel that cannot be matched is reported, never silently piled up.

The Mosaic Wizard reads the focal length, pixel size and sensor from your equipment profile and camera, sends the panels in the order of the pattern you chose, and warns that rotation turns the grid and not the camera. A Stop button now cancels a sequence or a mosaic, and mosaics work with native ZWO ASI and Canon cameras.

One Copy Only

The previous release, 1.4.5, carried two fixes of the same family. The application could be started twice: a second copy ran beside the first, the embedded web server drifted to another port, and the MCP server for AI assistants crashed at start-up with address already in use, so the assistant integration silently went missing. The installer’s own Launch option makes an accidental double launch easy. A second launch now says the application is already running, and exits — while the automatic restart after a frozen window still works.

And after connecting a native ZWO ASI camera, such as an ASI120 guide camera, the live-view buttons used to stay greyed out. Both live views now work with a native ASI, and a failure to start the video stream is reported instead of leaving a black image.

What Remains

No machine-learning model has ever been trained under a real sky here, so the corrected labelling is validated by construction rather than by data. PHD2 guiding was checked against PHD2 itself and against a simulated guider, not on a real camera. We make neither claim.

What Changed

A mount link that is watched and reported. PHD2 connecting at once, with a real RMS and honest units. Charts that draw. Machine-learning screens that describe the model that exists. Mosaics placed from shared stars. A second launch that exits instead of colliding.

What Didn’t

Anything under a real sky. This release was checked against simulators and against PHD2 itself, and its notes say so.

Software that is wrong loudly is easy to fix. This release was about the other kind: the application that is wrong quietly, in a calm voice, with a green indicator. The cure turned out to be unglamorous — read every message the program can show, and ask of each one whether it is true.
