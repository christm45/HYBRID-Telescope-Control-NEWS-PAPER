Audit

Third Full Audit: A Refraction Term With the Wrong Sign, and Stacking Engines That Never Started

Six reviewers, with every finding checked in the code before it was fixed. The refraction correction doubled the drift it was meant to remove, Stop left a correction rate in the mount, and the two Python stacking engines could not start under the bundled Python.
By Bogdan • November 2, 2026 • DEV LOG • v1.4.13 PRO

Interleaved Cycle, 900 s

1,061″ → 18″
bench error after capping long cycles

Interleaved mode accepted up to 900 seconds between plate solves. The cycle is now capped at 300 seconds; on the tracking bench the error of the 900-second scenario fell from 1,061″ to 18″.

The third full audit of the program, its interface and its settings took place on November 2, with particular attention to advanced tracking. Six reviewers worked in parallel; each finding was verified in the code before a fix was written, and the fixes came with tests. They shipped in v1.4.13.

Tracking

The refraction feed-forward — a predicted rate that compensates for the change of atmospheric refraction as a target moves — had the correct magnitude and the wrong sign, so it doubled the drift instead of removing it. Pressing Stop left the closed-loop correction rate in the mount’s driver. Dithers, comet rates and GOTOs were fought by the loop, which saw the intentional move as an error; they now suspend the loop and resume it afterwards. Tracking settings are stored per equipment profile.

The refraction term was correct in magnitude and wrong in sign: it added the error it was meant to subtract. On the feed-forward

A site of 0°/0°, or one estimated from the IP address, could be written into the mount as its location; the program no longer does this. The home position of a German equatorial mount had been placed at hour angle 0 instead of ±6 hours. Positions sent to the mount use the apparent place, checked against Meeus to better than 1.5″.

Stacking

The multichannel and project stacking engines, written in Python, never started under the embedded Python, because its path file did not include the folder of the script. They now start. Colour frames are normalised per channel; the uncovered borders left by alignment are excluded on the GPU and with local normalisation as well; calibration masters are built in horizontal bands like the lights, and flats are levelled. The half-flux radius used by autofocus came out at about 15 pixels on sharp stars; this is fixed.

Pointing, Polar Alignment and Rotator

Live refinement of the three-point polar alignment now works in an Earth-fixed frame. The pointing-model card in the Tracking tab opens the pointing-model window directly, and the rotator’s travel limits can be set in the equipment profile.

Licence Keys

Licence keys are now signed with ECDSA. The program contains only the public key and checks the key offline. A key in the older format starts the program in Free mode with a message, and the stored file is kept; owners of an older key can ask for a replacement.

What Changed

Refraction sign; Stop clears the correction rate; long interleaved cycles capped; intentional moves suspend the loop; no placeholder or IP site written into the mount; Python stacking engines start; per-channel normalisation; signed licence keys.

What Didn’t

Nothing in this release has run under a real sky. Before packaging: GUI tests 1,172 of 1,172, imaging 58 of 58, image processing 598 of 599 (the remaining one passes when run alone).
