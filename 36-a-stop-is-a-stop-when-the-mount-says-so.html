The November Re-Audit: A Stop Is Reported Only When the Mount Confirms It

A full re-audit of the code, the features and the interface, and its fixes, each with a test that runs the code. The first finding concerned the previous audit itself: a fix it recorded as done had never been made.
By Bogdan • November 15, 2026 • DEV LOG • v1.4.16 PRO

Between November 13 and 15 the program was re-audited completely: mount, cameras, image processing, interface and code, by five reviewers who ran probes rather than only reading. The first finding concerned the previous audit: its notes said that a sequence’s frame counter was no longer reset, and it still was. Since then a fix counts as done only when a test executes it; the report also counted 263 existing tests that only search the source text.

Mount

About forty calls treated a stop as done even when the mount had refused it. A stop is now reported only when the mount confirms it. New STOP MOUNT, Park, Unpark and Home buttons are available, and Esc stops everything, including when the focus is in the sky chart. A roll-off roof closes only after a confirmed park; the program does not unpark when conditions are unsafe or the roof is closed; and the watchdog stops the axes before it restarts anything.

A fix counts as done only when a test executes it. The rule adopted after the first finding

Scheduler

The Target Scheduler window, the web remote and voice commands now use one scheduling engine, wired to the filter wheel, PHD2, the roof, camera warming, the Safety Monitor and the weather. The night window is computed from the solar noon of the site. In the Target Scheduler window, a time and a right ascension were combined in different units: M31, at 68° altitude, was displayed at 0.1°.

Cameras and Imaging

Only one exposure at a time can run on the imaging camera; the rule also applies to captures and autofocus started from the web remote or by voice, and to the scheduler. Filters are selected by name, and a filter wheel that does not respond is a failure. Canon CR2 files are decoded as true 14-bit RAW (see dispatch 35). Star detection no longer depends on the black level: 16-bit and 14-bit versions of the same real frames give the same stars.

Stacking

Advanced Stacking works in colour and accepts the calibration frames or masters chosen by the user. The frame quality filter was tuned on real lights. Satellite trails are rejected, including in drizzle: without dithering, the old rejection masked all the clean frames along a trail and left an empty line at −2,003 ADU; a vote now masks only the minority side, at −4 ADU. The GPU checkbox is now a real master switch, and several windows and services that did nothing were removed.

What Changed

Stops confirmed by the mount; STOP, Park, Unpark and Home buttons; Esc stops everything; one scheduler engine; one exposure at a time on the imaging camera; colour and chosen calibration in Advanced Stacking; trail rejection in drizzle.

What Didn’t

Still to be verified under a real sky: the field derotator, the meridian flip during a scheduled night, live polar alignment and the pointing model. The full GUI test suite passed with no failure (1,386 tests) when run on its own.
